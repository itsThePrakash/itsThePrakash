## About me

> *Small sites, plain HTML, and things that stay up.*

I'm **Prakash Gothwal**, usually just Prakash. I'm from Kolwa, a village in Dausa district, Rajasthan, and I studied CSE at MNIT Jaipur from 2022 to 2026. I started **EkGuru**, a Hindi learning site with 2,754 static pages and 31 language bridges, and **Print$Buddy**, a print delivery service for hostel rooms that I ran through college.

You'll also find me as **Prakash MNIT**, **Prakash CSE**, **Prakash Kolwa** or **Prakash Dausa**. Same person. There is a longer bio at [itstheprakash.vercel.app/about](https://itstheprakash.vercel.app/about).

My house style: **zero dependencies, zero framework runtimes, sub-second first paint, and a fallback for every link in the chain.** My portfolio is generated from one data file by a dependency-free Node build — <kbd>node src/build.mjs</kbd>, nothing else. This README mirrors the same links.

## How this is built

```mermaid
graph LR
    subgraph SOURCE["src/ · one source of truth"]
        D["data.mjs<br/><small>profile · projects · orgs · socials · achievements</small>"]
        C["css.mjs · js.mjs · art.mjs"]
        B["build.mjs<br/><small>zero-dependency generator</small>"]
        D --> B
        C --> B
    end

    B --> OUT["dist/<br/><small>index · resume · 404 · medals · og · sitemap</small>"]

    OUT --> V["Vercel Edge<br/><small>Brotli · immutable cache · HSTS</small>"]
    OUT --> GH["GitHub Pages / Profile README"]

    V --> LIVE["itstheprakash.vercel.app"]
    V --> API["/api/live<br/><small>edge-cached telemetry</small>"]

    API -->|"1 · edge"| GHREST["api.github.com"]
    API -->|"2 · snapshot"| SNAP["data/github.json"]
    API -->|"3 · valid JSON"| NONE["graceful none"]

    GHREST --> WF["GitHub Actions<br/><small>6-hourly snapshot refresh</small>"]
    WF -->|commits| SNAP

    LIVE -->|"every card"| P1["ekguru.shop"]
    LIVE -->|"every card"| P2["printsbuddy.vercel.app"]
    LIVE -->|"every card"| P3["saranshne.vercel.app"]

    style SOURCE fill:#0d1117,stroke:#7c5cff,color:#a8b2cf
    style OUT fill:#0d1117,stroke:#00e5ff,color:#a8b2cf
    style V fill:#0d1117,stroke:#ff4d8d,color:#a8b2cf
    style LIVE fill:#7c5cff,stroke:#7c5cff,color:#ffffff
    style API fill:#0d1117,stroke:#22e07a,color:#a8b2cf
```
